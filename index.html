Manual de Extração de Relatórios

Para que a auditoria funcione perfeitamente, é necessário exportar os arquivos do sistema ERP utilizando os caminhos exatos listados abaixo:

1. Vendas (Entrada)

Caminho no sistema:

VENDAS ➔ RELATÓRIOS ➔ CLIENTE ➔ CLIENTE + PRODUTO ANALÍTICO POR VENDA * Para conferir vendas entre lojas, coloque a loja a ser analisada no campo Cliente.

2. Transferência (Entrada)

Caminho no sistema:

VENDAS ➔ RELATÓRIOS ➔ OUTRAS NOTAS ➔ ANALÍTICO POR PRODUTO

3. Saída (Ficha de Estoque)

Caminho no sistema:

ESTOQUE E COMPRAS ➔ MOVIMENTO DE ESTOQUE ➔ FICHA DE ESTOQUE * Filtrar exclusivamente o movimento: 56 – venda.
